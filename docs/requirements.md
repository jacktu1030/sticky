# 需求规格

## 背景

雨然日历面向需要在桌面或手机上长期保留便签、查看农历/节日、管理提醒和查看天气的个人用户。项目强调本地优先、启动即用、低配置成本和轻量界面。

## 目标

- 提供一个常驻式个人便签和日历工具。
- 支持常用日期提醒，覆盖公历和农历场景。
- 在一个入口内展示日期、农历、节日、日程、天气和时钟信息。
- 在 Android 上尽量通过原生闹钟能力提高提醒可靠性。
- 保持数据本地存储，避免依赖账号体系。

## 用户角色

- 个人用户：记录便签、日程、纪念日、生日、缴费、工作例会等。
- 维护者：维护节假日数据、打包发布应用、修复平台兼容问题。

## 范围

### 已包含

- 便签文本保存和恢复。
- 月视图日历。
- 今日事项面板。
- 公历日期、农历日期、生肖/星座相关显示。
- 固定节日、农历节日、节气、法定休假日和调休上班日标记。
- 日程新增、列表查看、编辑、删除和日期菜单查看。
- 日程完成/撤销完成状态。
- 提醒新增、列表查看、删除、提前通知和到点提示。
- 提醒新增和编辑时可同步写入日程。
- 主题切换。
- 天气定位、手动城市查询和 7 日预报。
- Windows 桌面悬浮时钟。
- Windows 桌面本地数据加密保存。
- Windows 桌面数据导入/导出。
- Windows 桌面和 Android WebDAV 加密同步。
- Windows 桌面开机自启动可视化开关。
- Android 应用内时钟和桌面小组件。
- Android 通知权限、精确闹钟权限、开机恢复和前台服务。

### 暂不包含

- 账号登录。
- 多设备数据合并。
- 团队共享日历。
- 复杂重复规则，例如每月最后一个工作日。
- 完整备份/恢复 UI。
- 自动在线更新。

## 功能需求

### FR-01 便签

- 用户可以编辑一段自由文本便签。
- 应用应在内容变化后自动保存。
- 重启应用后应恢复上次保存的内容。

验收标准：

- 输入文本后关闭并重新打开应用，文本仍存在。
- 保存失败时桌面版应提示或记录错误，不应导致程序崩溃。

### FR-02 日历

- 用户可以查看当前月份日历。
- 用户可以切换上一月和下一月。
- 用户可以一键回到今天所在月份。
- 用户可以选择年份和月份后跳转查看。
- 每个日期应显示公历日、农历信息和必要节日标记。
- 今天、周末、节假日、调休日、有日程、有提醒日期应有可区分样式。

验收标准：

- 当前日期有明显标记。
- 跳转到其他月份后，日历不会被每分钟刷新自动拉回当前月。
- 点击“今天”后能回到当前日期所在月份。
- 设置了提醒或日程的日期在月视图中能被识别。
- 法定休假日显示“休”，调休上班日显示“班”。

### FR-03 日程

- 用户可以从工具栏打开今日事项面板，查看今天和明天的日程、提醒。
- 用户可以从日期菜单为某天添加日程。
- 用户可以从工具栏打开日程列表，按时间顺序查看全部日程。
- 用户可以从日程列表和日期菜单编辑已有日程。
- 用户可以从日程列表和日期菜单删除已有日程。
- 用户可以将日程标记为已办，也可以撤销已办状态。
- 用户添加或编辑日程时可以选择同时创建单次提醒。
- 日程支持可选时间前缀。
- 同一天可以保存多个日程。

验收标准：

- 添加后该日期出现日程标记。
- 今日事项面板应展示今天和明天的日程、提醒，并标出已过事项。
- 日程列表展示全部日程，未来日程排在已过日程之前。
- 已办日程应保留在列表中，使用弱化样式展示。
- 编辑后日期菜单展示更新后的日程内容。
- 删除最后一条日程后该日期不再显示日程标记。
- 勾选“同时提醒我”后，提醒列表中出现对应单次提醒。
- 重启应用后日程仍存在。
- 日期菜单能查看同一天的日程内容。

### FR-04 提醒

- 用户可以创建以下提醒类型：
  - 单次。
  - 每天。
  - 每周。
  - 每月。
  - 每年。
  - 每年农历。
  - 每月农历。
- 提醒包含时间、内容和类型参数。
- 从日程创建的提醒保存为普通单次提醒，并保留来源标记。
- 用户添加或编辑提醒时可以选择同步添加到日程。
- 用户可以查看、编辑、停用/启用和删除提醒。
- 到点后应弹出提醒或发送系统通知。

验收标准：

- 每种提醒类型能保存、展示和删除。
- 停用提醒后不参与日期提醒标记和 Android 原生闹钟调度，重新启用后恢复。
- 勾选“同步到日程”后，日程列表出现对应日程；重复提醒写入下一次触发日期。
- Android 版应提供日程列表入口，并在日期详情中同时展示当天提醒和日程。
- 单次提醒不允许选择已过去的时间。
- 重复提醒同一天不应重复弹出多次。
- Android 上支持的公历提醒应下发到原生 `AlarmManager`。

### FR-05 农历和节日

- 日历应显示农历日期。
- 支持农历传统节日。
- 支持 1900-2100 年范围内的农历查表能力。
- 节假日表需要人工维护到目标年份。

验收标准：

- 农历初一显示月份名，其余日期显示日名。
- 春节、元宵、中秋等农历节日能在对应日期显示。

### FR-06 天气

- 应用可根据系统定位或手动输入城市获取天气。
- 天气展示包含城市简称、天气图标/描述、温度。
- 用户可查看 7 日预报。
- 天气失败时应显示可理解的兜底状态。

验收标准：

- 网络可用且城市有效时能展示天气。
- 网络失败、定位失败、城市无效时不崩溃。
- Android 小组件可读取最近一次同步的天气摘要。

### FR-07 主题

- 应用提供多套预设主题。
- 桌面版支持自定义主题色。
- 主题选择应保存并在重启后恢复。
- 桌面版主题配置应可从右上角“设置”窗口进入。

验收标准：

- 切换主题后主界面、日历和按钮颜色同步变化。
- 重启后保留上次主题。

### FR-08 时钟

- 桌面版支持模拟时钟和数字时钟悬浮窗。
- Android 版支持应用内时钟显示。
- Android 版支持数字和模拟系统桌面小组件。

验收标准：

- 时钟每分钟或每秒按设计更新。
- 桌面版悬浮窗位置可保存。
- Android 小组件点击后可打开应用。

### FR-09 开机/后台

- Windows 桌面版可注册或取消当前用户开机自启动。
- 用户可以从右上角“设置”窗口查看并切换开机自启动状态。
- Android 版开机后应尝试恢复闹钟和前台服务。

验收标准：

- Windows 注册表 `Run` 项存在且指向当前程序时视为启用。
- 从设置窗口开启后应写入 `Run` 项；关闭后应删除对应注册表值。
- Android 收到 `BOOT_COMPLETED` 后启动服务并触发应用恢复。

### FR-10 数据加密与备份

- Windows 桌面版应将 `notes.json` 加密保存。
- 应支持读取旧版明文 `notes.json` 并在下次保存时自动迁移为加密格式。
- 用户可以导出加密备份。
- 用户可以在确认风险后导出明文 JSON。
- 用户可以导入加密备份或明文 JSON，导入后覆盖当前数据并重新加密保存。
- 数据导入导出入口位于右上角“设置”窗口的“数据备份”中。

验收标准：

- 加密保存后的 `notes.json` 不直接暴露便签正文。
- 加密备份可在当前 Windows 用户下导入。
- 明文 JSON 可导入并迁移为加密本地数据。
- 导入覆盖前必须有确认提示。

### FR-11 WebDAV 加密同步

- Windows 桌面版可从右上角“设置”窗口配置 WebDAV 同步。
- Android 版可从主界面云同步入口配置 WebDAV 同步。
- 配置包含 WebDAV 地址、账号、应用密码、远程文件路径、同步密码和启动时自动同步开关。
- 云端同步文件必须使用同步密码加密，不能上传明文业务数据。
- 用户可以测试 WebDAV 连接、立即同步、上传本机覆盖云端、下载云端覆盖本机。
- 下载云端覆盖本机前必须先生成本机冲突备份。
- 上传本机覆盖云端时，如果云端已有数据，应先生成云端冲突备份。
- 当本机和云端都在上次同步后修改过时，应提示用户选择保留方向。

验收标准：

- Windows WebDAV 配置写入本机 `sync_config.json`，并使用 DPAPI 加密保存。
- Android WebDAV 配置写入应用私有目录 `sync_config.json`。
- 云端同步文件为 `pbkdf2-sha256+aes-256-gcm` 加密封套。
- 同步密码错误时不能解密云端文件，并应提示失败。
- 云端不存在同步文件时，首次立即同步应上传本机数据。
- Android 手机首次同步已有云端文件时应优先下载云端；当手机本机没有提醒/日程而云端有提醒/日程时，也应优先下载云端。
- 云端较新并确认下载后，主界面数据刷新且本机旧数据保留为冲突备份。

## 非功能需求

- 可用性：主要操作不超过两层弹窗。
- 可靠性：本地数据写入失败不能导致数据结构损坏。
- 性能：启动后日历渲染应在普通个人设备上保持流畅。
- 兼容性：Windows 桌面版优先支持 Windows 10/11；Android 版优先支持 Android 8+。
- 隐私：便签、提醒、日程默认只保存在本机；启用 WebDAV 同步后只上传加密后的同步文件。
- 可维护性：节假日、提醒类型、数据字段和平台桥接需要有文档记录。

## 发布验收

- 桌面版能直接运行 `python sticky_note.py`。
- 桌面版能使用 PyInstaller 规格文件完成打包。
- Android 版能完成 `flutter pub get` 和 `flutter build apk --release`。
- 新增或修改提醒字段时，桌面版与 Flutter 版的数据文档已同步更新。
- 权限和外部服务变更已同步更新隐私文档。
