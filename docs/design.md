# 产品与交互设计

## 设计原则

- 信息集中：便签、日期、天气和提醒放在同一工作区，减少切换。
- 常驻轻量：桌面版适合放在屏幕边缘，Android 版适合快速查看和创建提醒。
- 本地优先：不引入账号、同步或复杂配置。
- 直接操作：日期、天气、时钟、提醒按钮均可直接触发对应操作。

## Windows 桌面版

### 主窗口

主窗口由以下区域组成：

- 标题/拖拽区域：用于移动无边框窗口。
- 日期信息栏：显示当前日期、农历/节气信息和天气摘要。
- 便签区：多行文本输入，内容自动保存。
- 标题栏右侧：包含设置、最小化和关闭入口。
- 工具栏：包含今日、提醒、日程、主题、日历展开/收起和时钟等入口。
- 日历区：显示当前月份，可切换上一月/下一月，也可回到今天或跳转指定年月。

### 日历交互

- 点击没有提醒的日期：打开日期菜单，可添加提醒或日程。
- 点击有提醒的日期：优先展示该日期提醒列表。
- 日期菜单展示已有日程，并提供新增、编辑和删除入口。
- 月份切换、跳转年月和返回今天后保持当前主题和日期标记。
- 用户跳转到非当前月份后，日历不会被每分钟时间刷新自动拉回当前月份；仅跨天时刷新今天标记。

### 日程交互

工具栏“今日”入口打开今日事项面板：

- 汇总今天和明天的日程、提醒。
- 按时间升序展示。
- 已过事项使用弱化色并标记“已过”。
- 底部提供添加今日日程入口。

新增和编辑日程共用同一弹窗：

- 顶部显示操作标题和日期。
- 使用小时、分钟下拉框选择日程时间。
- 使用多行输入框填写日程内容。
- 可勾选“同时提醒我”，并选择准时或提前通知时间；保存时创建对应单次提醒。
- 底部提供“取消”和“添加”或“保存”按钮。
- 弹窗尺寸需要保证底部按钮完整可见，内容输入区不挤压操作按钮。

工具栏“日程”入口打开日程列表：

- 列表汇总所有日期的日程。
- 未来日程按时间升序显示，已过日程放在后面。
- 每条日程提供完成/撤销、编辑和删除操作。
- 已办日程保留在列表中，使用灰色弱化并标记“已办”。
- 空列表显示“暂无日程”和添加今日日程入口。

删除日程前需要二次确认。删除某天最后一条日程后，该日期的日程标记消失。

### 提醒交互

新增提醒弹窗包含：

- 类型选择。
- 动态日期/周期字段。
- 时间选择。
- 提醒内容。
- “同步到日程”选项。

提醒类型变化后，日期输入区域随类型切换。单次农历提醒在保存时转换为对应公历触发时间，但保存时保留农历标记。勾选“同步到日程”时，会把该提醒的下一次触发时间写入日程列表。

### 天气交互

- 天气摘要显示在日期信息栏右侧。
- 点击天气图标或文字打开 7 日预报。
- 点击编辑入口可手动输入城市。
- 首次无法定位或无天气位置时提示用户输入城市。

### 设置窗口

标题栏右上角提供“设置”入口，点击后打开设置窗口，包含：

- 主题设置：打开主题配置，调整便签、日历和按钮颜色。
- 设置开机自启动：开启或关闭 Windows 当前用户开机自启动。
- 设置城市：打开天气城市设置。
- 云同步：配置 WebDAV 地址、账号、应用密码、远程文件和同步密码，并支持测试连接、立即同步、上传本机、下载云端。
- 数据备份：展开导出加密备份、导出明文 JSON 和导入数据。

明文 JSON 导出前需要二次确认。导入数据前需要提示会覆盖当前数据，导入成功后主界面立即刷新便签、提醒、日历、主题和天气状态。云同步覆盖本机前需要先生成本机冲突备份；检测到两端都修改过时需要让用户选择下载云端或上传本机。开机自启动开关只修改当前用户注册表，不再启动时自动弹窗询问。

### 悬浮时钟

- 支持模拟和数字样式。
- 数字时钟包含日期、星期、年内天数、周数和天气摘要。
- 悬浮窗可拖拽，位置写入本地数据。
- 主题变化时同步更新时钟视觉。

## Android/Flutter 版

### 应用主界面

Android 版延续桌面版信息结构：

- 顶部可收缩图标工具栏，包含日历、主题、时钟、云同步、添加提醒、日程列表和提醒列表入口。
- 日程列表和提醒列表入口固定在工具栏右侧，存在数据时分别显示数量角标。
- 顶部日期和天气信息。
- 便签编辑区。
- 操作按钮区域。
- 可展开的月历。
- 可选时钟区域。

界面基于 Flutter Material 组件实现，强调移动端可点击区域和弹窗输入。

### 云同步

- 云同步设置包含 WebDAV 地址、账号、应用密码、远程文件、同步密码、启用开关和启动时自动同步开关。
- 支持测试连接、立即同步、上传本机覆盖云端、下载云端覆盖本机。
- 下载云端成功后，状态提示会显示本次云端数据中的提醒和日程数量。
- 覆盖本机或云端前保留冲突备份。
- 使用与 Windows 桌面版一致的云端加密封套，便于多电脑和手机共用同一个 WebDAV 文件。
- 手机首次同步已有云端文件时优先下载云端数据；当手机本机没有提醒/日程而云端有提醒/日程时，也优先下载云端，避免空手机或天气刷新把桌面端数据覆盖掉。

### 日历和日期操作

- 点击日期打开菜单。
- 可从菜单添加日程或提醒。
- 日期菜单会同时展示当天已有提醒和已有日程，避免同一天有提醒时看不到日程。
- 日期菜单中的提醒支持编辑、停用/启用和删除。
- 日期菜单中的日程支持标记已办/未办、编辑和删除。
- 有提醒的日期在右上角显示小红点；有日程的日期显示日程标记。
- 切换月份时保持当前筛选和主题状态。

### 日程和提醒管理

- 日程列表汇总所有日期的日程，按未办优先和时间顺序展示。
- 日程列表中的每条日程可勾选已办/未办、编辑或删除；空列表提供添加今日日程入口。
- 提醒列表中的每条提醒可编辑、停用/启用或删除。
- 停用的提醒不参与日期小红点和 Android 原生闹钟调度，列表中使用灰色弱化样式。

### 天气

- 启动后优先使用已保存经纬度刷新天气。
- 没有保存位置时调用 Android 原生定位获取最近一次位置。
- 定位失败时显示“设置天气”，用户可手动输入城市。
- 天气信息保存后同步给 Android 数字时钟小组件。

### 提醒

Flutter 侧维护完整提醒列表和展示。
Android 原生侧接收支持的提醒类型并注册系统闹钟：

- `once`
- `daily`
- `weekly`
- `monthly`
- `yearly`

农历重复提醒目前不下发给原生闹钟，只在应用运行时由 Flutter 侧检查。

### Android 桌面小组件

数字时钟小组件：

- 显示时间、日期、年内天数、周数和天气。
- 每分钟通过 `AlarmManager` 刷新。
- 点击打开应用。

模拟时钟小组件：

- 使用原生 Bitmap 绘制表盘。
- 每分钟刷新。
- 点击打开应用。

## 视觉规范

### 主题色

预设主题包含：

- yellow
- green
- blue
- pink
- purple
- white
- dark

每套主题至少包含：

- `bg`：主背景。
- `fg`：主要文字。
- `today`：今天标记。
- `holiday`：节假日标记。
- `weekend`：周末背景。

### 日期标记优先级

建议展示优先级：

1. 今天。
2. 法定休假/调休。
3. 提醒。
4. 日程。
5. 节日/节气。
6. 周末。

## 错误与空状态

- 无提醒：显示“暂无提醒”。
- 天气加载中：显示“天气加载中”。
- 天气失败：显示“天气暂不可用”或“天气查询失败”。
- 未设置天气：显示“天气未设置”或“设置天气”。
- 保存失败：桌面版弹出警告，Flutter 版应至少返回保存失败状态供调用方处理。

## 可访问性建议

- 关键颜色标记应辅以文字或符号，例如“休”“班”。
- 提醒和日程文本应允许换行或截断，避免撑破日期格。
- 弹窗按钮应保持明确文字：取消、添加、保存、删除。
