# 测试方案

## 当前状态

当前仓库自动化测试覆盖不足：

- 桌面版没有单元测试或 UI 自动化测试。
- Flutter 子项目存在模板测试 `sticky_android/test/widget_test.dart`，但该测试仍引用 `MyApp` 和计数器模板；当前入口是 `StickyApp`，因此该测试需要改造后才有意义。
- Android 原生闹钟、小组件和权限流程主要依赖人工验证。

## 测试目标

- 确认便签、日程、提醒、天气和主题不会丢失数据。
- 确认日历标记和农历计算在常见日期正确。
- 确认 Android 后台提醒和小组件在目标机型上可用。
- 确认构建产物可启动、可保存、可退出。

## 桌面版人工回归

### 启动和保存

1. 运行 `python sticky_note.py`。
2. 输入便签内容。
3. 切换主题。
4. 关闭应用并重新打开。
5. 确认便签和主题恢复。
6. 确认右上角“设置”按钮可见，点击后打开设置窗口，包含“主题设置”“设置开机自启动”“设置城市”“云同步”“数据备份”。
7. 从“设置”窗口切换开机自启动，确认窗口状态和当前用户 `Run` 注册表项同步变化。
8. 检查 `notes.json` 为加密封套，不能直接看到便签正文。

### 日历

1. 切换上一月、下一月。
2. 点击“今天”，确认回到当前日期所在月份并显示今天高亮。
3. 点击“跳转”，选择其他年月，确认日历切换到指定月份。
4. 在跳转后的月份停留至少 1 分钟，确认不会被自动拉回当前月。
5. 检查周末、节日、休班标记。
6. 点击一个日期添加日程。
7. 确认添加日程窗口底部“取消”和“添加”按钮完整可见。
8. 勾选“同时提醒我”，选择提前量后保存。
9. 确认该日期显示日程标记，提醒列表出现对应单次提醒。
10. 打开工具栏“今日”，确认今天和明天的日程、提醒集中展示。
11. 打开工具栏“日程”，确认日程列表展示该日程。
12. 从日程列表勾选“已办”，确认日程保留并变为弱化样式；取消勾选后恢复。
13. 从日程列表编辑该日程，确认编辑窗口底部“取消”和“保存”按钮完整可见，内容更新。
14. 从日程列表删除该日程，确认最后一条删除后日程标记消失。

### 提醒

1. 添加 1 分钟后的单次提醒。
2. 勾选“同步到日程”，保存后确认日程列表出现对应日程。
3. 等待到点弹窗和提示音。
4. 添加每天、每周、每月、每年提醒。
5. 勾选重复提醒的“同步到日程”，确认写入的是下一次触发日期。
6. 打开提醒列表确认展示文本正确。
7. 删除提醒后确认列表数量和日历标记更新。

### 农历

1. 检查春节、中秋、端午等农历节日。
2. 添加农历生日提醒。
3. 检查有农历提醒的日期标记。

### 天气

1. 首次启动时确认天气加载状态。
2. 手动输入城市。
3. 打开 7 日预报。
4. 断网后刷新，确认 UI 不崩溃并显示失败状态。

### 悬浮时钟

1. 打开模拟时钟。
2. 切换数字时钟。
3. 拖拽时钟位置。
4. 重启后确认样式和位置恢复。

### 数据导入导出

1. 从“设置”窗口的“数据备份”导出加密备份。
2. 导入该加密备份，确认便签、提醒、日程和主题恢复。
3. 从“设置”窗口的“数据备份”导出明文 JSON，确认导出前有风险确认。
4. 导入明文 JSON，确认导入后本地 `notes.json` 重新以加密封套保存。
5. 尝试导入无效 JSON，确认应用提示失败且不覆盖当前数据。

### WebDAV 加密同步

1. 从“设置”窗口打开“云同步”，填写 WebDAV 地址、账号、应用密码、远程文件和同步密码。
2. 点击“测试连接”，确认连接成功或失败提示清晰。
3. 云端无同步文件时点击“立即同步”，确认本机数据上传成功。
4. 检查云端文件为 `yuran_calendar_webdav_sync` 加密封套，不能直接看到便签正文。
5. 修改本机数据后再次同步，确认云端被更新。
6. 在另一台电脑或 Android 手机使用相同 WebDAV 配置和同步密码下载，确认便签、提醒、日程和主题恢复。
7. 使用错误同步密码下载，确认解密失败且不覆盖本机数据。
8. 手动制造本机和云端同时修改，确认应用提示同步冲突，并生成 `sync-conflict-*` 备份。

## Android 人工回归

### 基础功能

1. `flutter run` 安装应用。
2. 输入便签并重启应用。
3. 切换主题。
4. 添加日程和提醒。
5. 打开提醒列表，确认提醒可编辑、停用/启用和删除；停用后日期小红点和原生闹钟调度不再包含该提醒。
6. 打开日程列表，确认同步或新增的日程按日期展示。
7. 在日程列表中勾选已办/未办，确认日程保留并切换灰色弱化样式。
8. 在日程列表中编辑和删除日程，确认日期菜单和日历标记同步刷新。
9. 在窄屏设备上确认顶部日程列表和提醒列表图标始终可见，存在数据时显示数量角标。

### WebDAV 同步

1. 点击顶部云同步入口，填写 WebDAV 地址、账号、应用密码、远程文件和同步密码。
2. 点击“保存”，确认弹窗内显示“配置已保存”，关闭后重新打开配置仍在。
3. 点击“测试”，确认弹窗内显示连接成功或失败状态。
4. 确认“保存配置”“测试连接”“立即同步”“上传本机”“下载云端”为内容区大按钮，不依赖弹窗底部小按钮。
5. 地址留空时点击“测试连接”，确认当前弹窗内立即显示“请填写 WebDAV 地址”。
6. 点击“立即同步”“上传本机”“下载云端”，确认当前弹窗内立即显示执行中、成功或失败状态。
7. 手机首次配置已有云端文件时点击“立即同步”，确认优先下载 Windows 桌面版上传的同一云端同步文件，并提示本机旧数据已备份和提醒/日程数量。
8. 修改手机便签后再次同步，确认 Windows 桌面版可下载更新。
9. 使用错误同步密码下载，确认解密失败且不覆盖手机本地数据。
10. 制造本机和云端同时修改，确认手机端提示同步冲突并生成本地冲突备份。
11. 手机本机没有提醒/日程而云端有提醒/日程时点击“立即同步”，确认不会提示“本机数据较新”，而是下载云端数据。
12. Windows 端创建每天、每周、每月、每年提醒后同步到手机，确认提醒列表和日历日期小红点正常显示。
13. Windows 端创建普通日程和已办日程后同步到手机，确认日程列表可见，日期菜单中普通日程正常显示、已办日程灰色删除线显示。
14. 同一日期同时有提醒和日程时，点击日期确认两类内容都显示，并可从日期菜单编辑、停用/启用或删除提醒，标记已办/未办、编辑或删除日程。

### 权限

1. 首次启动时检查通知权限请求。
2. Android 12+ 检查精确闹钟授权页面。
3. 检查忽略电池优化请求。
4. 检查定位权限请求。

### 原生提醒

1. 添加 2 分钟后的公历单次提醒。
2. 锁屏等待。
3. 确认声音、振动、横幅或全屏通知。
4. 添加每天/每周提醒，确认可触发并重新安排。

### 小组件

1. 添加数字时钟小组件。
2. 添加模拟时钟小组件。
3. 等待跨分钟刷新。
4. 点击小组件确认打开应用。
5. 设置天气后确认数字小组件显示温度和天气图标。

### 开机恢复

1. 添加未来提醒。
2. 重启手机或模拟器。
3. 确认前台服务启动。
4. 到点确认提醒触发。

## 建议自动化测试

### Python

优先拆出纯函数并覆盖：

- `lunar_to_text`
- `get_constellation`
- `weather_code_to_text`
- `weather_code_to_icon`
- 提醒匹配逻辑。
- 日期 key 和日程数据读写。

建议新增：

```text
tests/test_calendar.py
tests/test_reminders.py
tests/test_weather_format.py
```

### Flutter

建议替换模板测试：

- 能正常构建 `StickyApp`。
- 初始界面包含应用标题或核心按钮。
- 添加提醒弹窗能打开。
- `Reminder.toJson/fromJson` 往返一致。
- `WeatherInfo.toJson/fromJson` 往返一致。
- `dateKeyOf` 格式正确。
- `WebDavSyncService` 能解密 Windows 端生成的同步封套。

### Android 原生

可通过 instrumentation 或 Robolectric 覆盖：

- MethodChannel 参数解析。
- `ClockWidgetUpdater` 时间和日期格式。
- `WidgetWeatherStore` 保存和读取。
- `AlarmReceiver` 重复提醒 intent 字段。

## 发布阻断项

以下问题应阻断发布：

- 应用无法启动。
- 保存后重启数据丢失。
- Windows 桌面版无法读取已加密的 `notes.json`。
- 公历单次提醒无法触发。
- Android 通知权限或精确闹钟权限流程完全不可用。
- 构建产物缺少图标或关键资源。
- 天气失败导致崩溃。

## 非阻断但需记录

- Open-Meteo 服务临时不可用。
- 定位返回旧位置。
- 特定厂商系统限制后台保活。
- 农历重复提醒未下发 Android 原生闹钟。
