# 文档索引

本目录汇总雨然日历当前项目文档。文档按“先理解产品，再理解实现，再交付和维护”的顺序组织。

## 产品文档

- [需求规格](requirements.md)：目标用户、范围、功能需求、非功能需求和验收标准。
- [产品与交互设计](design.md)：桌面版、Android 版、日历、提醒、天气和时钟的交互设计。
- [路线图与已知限制](roadmap.md)：当前限制、短期修复项和后续演进方向。

## 技术文档

- [技术架构](architecture.md)：模块划分、数据流、平台差异和关键技术决策。
- [数据模型](data-model.md)：本地 JSON 存储、提醒对象、日程、天气和主题字段。
- [隐私与安全](security-privacy.md)：本地数据、权限、外部服务、敏感文件和发布检查。

## 工程文档

- [构建与发布](build-and-release.md)：Windows 桌面版、Android APK、Apple 平台构建说明。
- [测试方案](testing.md)：人工回归清单、自动化测试现状、风险场景和发布验收。

## 维护约定

- 功能行为以当前代码为准，文档需要随功能变更同步更新。
- 涉及数据字段、权限、外部网络服务、打包命令的改动，必须同步更新对应文档。
- `notes.json`、`sync_config.json`、token、构建产物和本地 SDK 不属于文档或源码内容，不应提交。
